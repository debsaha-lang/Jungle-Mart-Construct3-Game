# Jungle Mart – Idle Shop Management Game for Android

## Overview

Jungle Mart is a 2D idle shop management game developed for Android devices using Construct 3. The game focuses on resource collection, customer interaction, inventory handling, and upgrade progression systems within a jungle-themed supermarket environment.

The project was developed as a Diploma Major Project for the Department of Computer Science and Technology.

## Gameplay Features

* Player-controlled monkey character
* Customer queue and purchase system
* Product collection and stocking
* Unlockable stalls and upgrades
* Assistant staff automation
* Upgrade system for speed, stamina, and stack level
* HUD and touch controls
* Coin collection mechanics

---

## AI and Pathfinding System

The game uses Construct 3 event-sheet programming to control NPC behavior. Customers move between different states such as:

* Entry Gate
* Product Stall
* Cashier Counter
* Exit Area

A grid-based pathfinding system is used for movement and obstacle avoidance inside the game map.
