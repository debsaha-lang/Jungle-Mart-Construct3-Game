# Jungle Mart – Idle Shop Management Game for Android

Jungle Mart is a 2D idle shop management game developed using Construct 3 for Android devices.

## Features

- Customer AI system
- Pathfinding behavior
- Upgrade system
- Unlockable stalls
- Staff automation
- Android APK export
- Google Play Store deployment

## Technologies Used

- Construct 3
- Android SDK
- Cordova
- GIMP
- Google Play Console

## Gameplay

The player controls a monkey character who manages a jungle-themed supermarket by collecting resources, stocking product stalls, serving customers, and upgrading systems.
