# Jungle Mart – Idle Shop Management Game for Android

## Overview

Jungle Mart is a 2D idle shop management game developed for Android devices using Construct 3. The game focuses on resource collection, customer interaction, inventory handling, and upgrade progression systems within a jungle-themed supermarket environment.

The project was developed as a Diploma Major Project for the Department of Computer Science and Technology.

## AI and Pathfinding System

The game uses Construct 3 event-sheet programming to control NPC behavior. Customers move between different states such as:

* Entry Gate
* Product Stall
* Cashier Counter
* Exit Area

A grid-based pathfinding system is used for movement and obstacle avoidance inside the game map.

## Construct 3 Programming Logic

The game logic was developed using Construct 3 event-sheet programming. Instead of traditional coding syntax, Construct 3 uses an event-driven visual scripting system where actions are executed when specific conditions become true.

The project contains multiple event sheets separated by functionality to improve organization and maintainability.

### Main Event Systems

#### Player System

The player system controls:

* Character movement
* Item carrying
* Product collection
* Stall interaction
* Coin collection

The player movement uses Construct 3's 8-direction behavior combined with touch controls for Android devices.

---

#### Customer AI System

The customer AI was implemented using pathfinding behavior and state-based logic.

Customers move through different gameplay states:

* Entering the market
* Moving to product stalls
* Waiting in queues
* Going to cashier
* Exiting the market

The AI system dynamically checks stall availability and uses Construct 3 pathfinding to avoid obstacles and move through the map efficiently.

---

#### Upgrade System

The upgrade system uses instance variables and coin-based unlocking mechanics.

Players can upgrade:

* Movement speed
* Carrying stack size
* Worker stamina
* Staff efficiency

Each upgrade modifies gameplay values in real time using event-sheet logic.

---

#### UI and HUD System

The game includes:

* Upgrade menu
* Coin display
* Settings buttons
* Character controls
* Unlock indicators

UI systems were developed using layered layouts and touch-based interactions for Android compatibility.
